# Agenda de Contatos (Android)

App Android com login, cadastro e listagem de contatos, com persistência local usando Room.

## Tecnologias
- Kotlin
- Android SDK
- Room (SQLite)

## Como rodar
1. Abra a pasta do projeto no Android Studio.
2. Aguarde o Gradle sincronizar.
3. Rode em um emulador ou dispositivo Android.
